[HOW TO READ THIS FILE]
- Each [RECORD nn.nn] describes one entity. Entity_ID is the local part of the entity IRI (id:<Entity_ID>); references to other entities are written as "Label (entity_id)".
- Verification_Status: verified-primary and verified-secondary are checked against a primary or an independent source; self-published comes from the author's own pages; unverified and archived-only must not be used as sole evidence.
- Verified_Against gives the independent page checked and the date it was last accessed (YYYY-MM-DD). Verification_Basis explains records with no web source (e.g. a document supplied by the author); link-not-rechecked means the link exists but was not re-checked in the last audit pass.
- Authority_URI lists identifiers and authority records of the SAME entity (schema:sameAs). Official_URL is a descriptive page. Do_Not_Follow_URL values are broken or unsafe addresses kept only so that they are not reused.
- Work, Instance (edition) and Item (library copy) are separate records: Instance_Of / Has_Instance and Item_Of / Held_By connect them.
- Section 10 lists page-level citation evidence: where a book or project is cited, on which page of the source document. Texts are paraphrases.
- Dates are ISO 8601. Prices and page counts follow the publisher's page; library counts are not used for the work.
- Giorgio Raffaelli is a different person from Baires Raffaelli (see Different_From).
